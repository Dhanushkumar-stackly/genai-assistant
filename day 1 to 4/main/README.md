# GenAI Assistant — Day 1 to Day 4

This package is organized as `main`, `day-1`, `day-2`, `day-3`, and `day-4`.

The Day 3 and Day 4 task folders follow the supplied practical roadmap.
Files are placed under the task they directly support. Missing roadmap
deliverables are explicitly marked instead of being invented.

## Structure

- `main/` — shared project configuration
- `day-1/` — no Day 1 implementation was present in the supplied ZIP
- `day-2/` — no Day 2 implementation was present in the supplied ZIP
- `day-3/` — five roadmap tasks
- `day-4/` — five roadmap tasks

## Note

The supplied ZIP contained no implementation files for Day 1 or Day 2, and
some Day 3/Day 4 roadmap deliverables were also absent. Those gaps are
documented in the corresponding task folders.
